# DougaSort

スマホ内の動画を、1本ずつ開かずにまとめて流し見して「ゴミ箱へ／✓済／タグ」で仕分ける Android アプリ。

## ビルド
1. Android Studio（最新版）をインストール
2. このフォルダを `Open` → Gradle Sync（初回は Gradle/SDK を自動取得）
3. USBデバッグ有効のAndroid実機（Android 11+）を接続して ▶ Run、または Build → Build APK(s)

## 使い方
- グリッドの各セルは、動画から抜いたフレームをパラパラ再生（システムのサムネイルをまず表示 → 自前のフレームに切り替え）
- セル上を横スワイプでスクラブ（なぞり始めた位置を基準に、上へ動かすほど粗く・下へ動かすほど0.5秒まで細かく）、タップでフル再生
- 「削除／#タグ／✓済」で仕分け。✓済は `Movies/確認済` アルバムへ移動（全ファイルへのアクセス許可が必要、確認なしで移動）。もう一度押すと元のアルバムへ戻る
- 上部で表示モード（未確認／済を除く／全部／済のみ／削除候補）、並び順（新しい順／古い順／サイズ大小）、アルバムで絞り込み
- チェックボックスで複数選択し、一括で✓済／削除印／タグ付け／アルバム移動
- 下部ボタンで、削除候補をまとめてゴミ箱へ（Android の確認あり、約30日で復元可能）
